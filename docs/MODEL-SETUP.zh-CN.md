# 模型配置

MiAxion 使用你配置的模型服务。在线服务的网络、账户和费用由该服务决定；本地服务需要你先启动并确保客户端能够访问。不要把应用支持某种预设理解为所有中转和部署均已验证兼容。

## 填写配置

在“设置”的模型配置区域新建配置，按实际服务填写：

| 配置项 | 填什么 |
|---|---|
| 名称 | 方便自己识别的名称，例如区分日常对话和本地测试 |
| 预设／服务类型 | 与服务实际提供的接口匹配；按服务文档和客户端字段提示选择 |
| 服务地址 | 服务提供的 API 地址或已启动的本地服务地址，不填网页聊天页面地址 |
| 模型 | 刷新目录后选择实际可用模型；以服务返回的模型身份为准 |
| 凭据 | 服务要求的个人 API Key；不需要时按实际界面和服务要求处理 |

地址是否包含版本路径、接口使用何种认证，依所选预设和服务要求填写，不统一猜测或重复拼接路径。中转地址由中转服务处理请求，选择原厂预设不会改变请求的实际接收方。

## 分三步确认

1. 刷新模型目录，确认服务地址、认证及该次目录请求可用。
2. 选择模型，按界面测试、保存并设为当前使用，再发一句普通文字聊天。
3. 需要知识或游戏工具时，启用对应功能，在资料已就绪或游戏已连接后试一个只读请求。普通聊天成功不证明工具调用、思考模式或所有参数都兼容。

本地模型无法访问时，先确认服务仍在运行、实际监听地址和端口与配置一致。同一台电脑上的服务通常使用回环地址，但不能把示例端口当成你的实际端口。

## 常见现象

| 现象 | 先检查 |
|---|---|
| 目录获取失败 | 地址、认证、网络和服务是否提供该接口；保留准确错误信息 |
| 能获取目录但不能回答 | 当前模型是否可用、服务额度、请求参数及返回错误 |
| 普通回答正常，工具请求失败 | 模型／服务的工具兼容性，以及客户端中该工具的实际状态 |
| 本地服务连接失败 | 服务进程、监听地址、端口；不要通过公开本地服务来代替排错 |
| 思考或参数被拒绝 | 该服务和模型是否支持所选选项，按返回错误逐项调整 |

不要把重试可能执行游戏动作的请求当作连接测试。向维护者反馈时提供服务类型、模型名称和脱敏错误，不提供 API Key。在线模型可能收到选定历史、知识片段和工具结果，详见 [数据使用说明](DATA-USAGE.zh-CN.md)。
