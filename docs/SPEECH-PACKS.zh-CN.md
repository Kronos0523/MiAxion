# MiAxion 离线语音包使用说明

下载：[百度网盘语音包](https://pan.baidu.com/s/1Attd0pmh-a8Bm9AV95nrvg?pwd=9999)，提取码 **9999**。按需选择下方运行包，不必全部下载。

说明更新：2026-10-28。适用 Windows x64；本目录七份语音安装包的清单版本均为 **1.0.0**，客户端发布版为 **0.2.0**，两者版本独立。本次只更新说明，未重打包或修改 ZIP。

音色包下载入口：[语雀音色包页面](https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/nwnaga50cazb2v93)。音色包用于选择朗读声音，与提供识别／朗读环境的语音运行包分开；按页面说明选择适配格式，再使用客户端对应的音色或参考音频入口导入。

## 1. 先选档位，再选安装方式

| 档位 | 识别／朗读引擎 | 运行条件与选择 |
|---|---|---|
| 轻量 | SenseVoiceSmall INT8／Hojo-TTS-Light 40M | CPU 路径，无需 CUDA；没有可用 CUDA 或游戏资源紧张时可选择 |
| 均衡 | Qwen3-ASR 0.6B／MeloTTS，参考音色可用 OpenVoice V2 | 需要可用的 NVIDIA CUDA 环境；默认中文音色或参考转换 |
| 高品质 | Qwen3-ASR 1.7B／GPT-SoVITS，默认 v2ProPlus | 需要可用的 NVIDIA CUDA 环境；参考音色或兼容完整音色包 |

均衡和高品质不会在 CUDA 不可用时自动改用 CPU；遇到显存不足或驱动初始化失败，可主动切换轻量。不能只凭显卡标称显存判断能否同时运行游戏、本地大语言模型和语音。

**只用一个档位，优先选对应独立包**，下载和安装步骤简单。打算安装多个档位时，可选“共享底座＋所需扩展”，共用部分运行环境。共享布局主要节省多档安装的磁盘重复，不等于降低推理显存，也不表示安装多个档位就同时运行多个档位。

## 2. 在客户端导入

1. 在“设置 → 语音”选择对应导入入口，不需要手工解压后运行包内 Python，也不需要自行向系统 Python 安装这些依赖。
2. 独立方式：使用“导入独立包”，选择 `independent-档位-1.0.0.zip`。
3. 共享方式：先用“导入共享底座”导入 `shared-base-base-1.0.0.zip`，再用“导入档位扩展”导入需要的 `pack-extension-档位-1.0.0.zip`。底座本身不能单独提供三档语音，扩展需匹配底座版本。
4. 选择档位、麦克风与扬声器，保存并等待准备就绪，再按页面显示的快捷键测试识别和朗读。

通用运行包、完整 GPT-SoVITS 音色 ZIP 和单独参考音频属于不同内容，使用各自导入入口。个人测试音色及个人配置不包含在本目录通用包中。许可审查资料 ZIP 也不是语音包，不要导入。

0.2.0 客户端自身附带 .NET/WPF，不代表语音模型已装好；语音 Python 环境和模型由本目录的语音包提供。安装后仍需满足系统原生运行库、显卡驱动及所选档位的设备要求，不自动安装系统组件。

## 4. 运行占用参考

下表来自 2026-09 的历史模型链评测摘录，**不是本次 0.2.0 整客户端重新测得的资源占用，也不是最低配置承诺**。当前仅复核到开发归档中的摘录，原始报告未在记录路径找到；无法据此补齐准确硬件、驱动、输入时长和完整采样条件。

| 档位 | 历史占用参考 | 测量口径 |
|---|---|---|
| 轻量 | 模型进程峰值约 **934 MiB RAM** | CPU 路径的模型进程指标，不是客户端、游戏及模型服务的内存总和 |
| 均衡 | 两模型合计已分配显存约 **2.6 GiB** | allocated 指标，不含完整驱动／框架保留量；CPU 内存峰值未取得 |
| 高品质 | 两模型合计已分配显存约 **5.25 GiB** | allocated 指标，不含完整驱动／框架保留量；CPU 内存峰值未取得 |

例如“2.6 GiB 已分配”不能解释为“3 GiB 显卡即可使用”。游戏、屏幕显示、本地大模型和参考音色会共同占用资源；语音模型准备就绪后也可能继续驻留，以便后续复用，停止播放不等于立即卸载模型。

CPU 占用率、整客户端 RAM 峰值、GPU 进程总占用、游戏 FPS／帧时间影响尚无可直接用于本说明的完整实测数据，暂不填写百分比或最低显卡型号。本轮未启动模型、录音或播放。

### 历史速度参考

同一历史记录的游戏运行期间 100 回合模型链：轻量中位／P95 **0.711／0.940 秒**，均衡 **0.371／0.462 秒**，高品质 **1.033／1.139 秒**。这是“合成输入 → 识别 → 固定回复 → 合成”的模型链，不含大语言模型回复、按键录音或实体播放，不是用户从说话到听见回答的总延迟，也不是不同硬件的速度保证。高品质采用不同参考音色或模型版本时不能直接套用。

## 5. 更新、卸载和常见问题

- 包版本仍为 1.0.0。已有同 ID／版本安装时，不要假定能直接原位覆盖；按客户端提示处理重复版本，不手工替换正在使用的文件。
- 当前客户端目录整理未要求重下语音包；已有正常工作的匹配包可沿用。升级客户端和复制 data 前先正常退出，保留旧目录及足够磁盘空间。
- 共享底座被扩展引用时不可直接删除。若要切换安装布局，先核对客户端的包管理提示，不将独立包和扩展目录混装。
- 提示缺少底座：先导入对应 ID 和版本的 shared-base。
- 提示 GPU／CUDA 不可用：检查设备及驱动，或切换轻量；不手工下载散装 DLL。
- 已就绪但无声音：分别检查扬声器、麦克风、音量、快捷键、当前档位及音色。识别与朗读分开测试。
- 首次准备较慢：查看阶段和错误提示；不要重复导入，也不要删除模型或索引来“加速”。
