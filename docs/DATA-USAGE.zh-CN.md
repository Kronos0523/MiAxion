# 数据使用与分享边界

本页说明现有功能的数据流，不代替所选模型或语音服务的隐私条款。

配置、会话、摘要、日志以及已安装的知识和语音资料主要位于程序旁的 `data`；资料工作区可以是另行指定的目录。模型密钥使用 Windows 凭据存储，配置保存引用。

使用在线模型时，当前问题、按配置允许的历史／摘要、工具描述和工具结果可能发送到你配置的端点。获准使用的游戏信息、知识片段、日志片段和工作区内容也可能作为上下文发送。**本地知识库不表示引用正文永远不会发往在线模型。**

使用本地模型时，请求发往你配置的本地服务；该服务自身是否联网、留存或记录内容，需查看其设置与说明。中转服务同样有自己的处理规则。

语音按安装包和配置运行。私人录音、参考音频、音色权重及聊天数据库不应作为普通问题附件公开上传。

## 反馈前检查

- 隐去 API Key、配对凭据、服务器地址和个人路径中的敏感部分。
- 仅提供必要截图和对应时段的错误片段，不上传整个 data、聊天库或游戏存档。
- 保留版本、错误码、复现步骤和必要请求 ID，避免脱敏后无法定位问题。
- 如确需完整私有现场，先与维护者约定传递范围和方式，不默认放进公开 Issue。

记录中出现的网页或工具文字只是资料，不代表额外操作授权。发生了游戏动作或文件写入时，反馈实际结果，不为收集样本反复执行。见 [问题反馈](FEEDBACK.zh-CN.md)。
