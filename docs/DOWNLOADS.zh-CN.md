# 下载与组件选择

**正式下载尚未发布。** 最终客户端和模组包仍由发布者整理；本页不把本地测试候选当成正式版本，也不提供尚不存在的附件链接。源码目录已可供审阅，见 [开发入口](BRIDGE-DEVELOPMENT.zh-CN.md)。

## 应该下载哪些内容

| 内容 | 何时需要 | 安装位置或用途 | 当前入口 |
|---|---|---|---|
| Windows x64 完整客户端 | 使用桌面助手 | 完整解压到独立目录，按随包说明启动 | 待最终包确认 |
| 基础 Bridge | 连接游戏、读取其提供的状态 | 匹配 Minecraft／加载器的实例 `mods` | 待逐平台附件清单 |
| JEI／REI 配方附属及其他模组附属 | 使用对应配方或模组能力 | 同一实例 `mods`；核对目标模组及前置依赖 | 待逐附属附件清单 |
| 语音包 | 语音输入／输出 | 按该包说明，在客户端语音设置中导入 | 已有百度网盘链接、提取码待补 |
| 知识包 | 需要对应资料 | 在“知识库”导入并启用 | 可分发内容及入口待确认 |
| SDK／协议源码与开发示例 | 开发附属或接入协议 | 独立开发工程；SDK／协议 JAR 不是 Mod | [源码入口](../components/public-contracts/README.zh-CN.md) |

只用文字聊天时，先取完整客户端并配置模型服务。语音包不用重复托管或上传；后续沿用发布者已有百度网盘分享。

## 版本与更新

每次 Release 分别列出客户端、各平台 Bridge、每个附属和语音包的版本、适用条件、是否需要更新。客户端升级不自动意味着其他组件必须重装。

正式附件还会登记真实文件名、字节数、SHA-256 和来源提交。语音包沿用已有交付记录，缺失的信息保持待补，不用文件夹日期猜版本。

安装见 [首次使用](QUICKSTART.zh-CN.md)，升级见 [备份与回退](UPGRADE.zh-CN.md)。源码构建通过不代替客户端包的 Windows 验证，也不代表已经发布可安装模组合集。
