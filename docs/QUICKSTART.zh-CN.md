# 安装与首次使用

本文对应 Windows x64 客户端 0.2.0 自包含公测候选，尚未公开上传。语音网盘入口已提供，模组附件待公开上传，请先查看 [下载说明](DOWNLOADS.zh-CN.md)。

## 1. 取得并启动完整客户端

将 `MiAXion-0.2.0-win-x64.zip` 完整解压到自己可读写的新目录，不在压缩包中运行，也不要只取 EXE。启动文件为 `client/MiAXion.exe`，保留 assets、说明和许可证文件。应用依赖与语言资源已经打包，无需手动寻找或搬动 DLL。

本包附带 .NET/WPF 10.0.13 x64，无需另装 .NET 或 SDK。ONNX 检索引擎另需 VC++ v14 x64；若提示缺少 MSVCP140／VCRUNTIME140，使用[微软官方运行库入口](https://aka.ms/vc14/vc_redist.x64.exe)，不从不明网站单独补 DLL。

程序旁的 `data` 保存本机配置、聊天及安装资料。新装不需要别人的 data。首次启动后，知识库恢复或语音准备可能仍在后台进行，以各功能状态为准。

已有用户请先读 [升级与回退](UPGRADE.zh-CN.md)，不要直接覆盖旧目录。

## 2. 先完成一次文字对话

在“设置”的模型配置区域点击“＋ 新建模型配置”，填写名称，选择与你实际服务匹配的预设、服务地址和模型；需要凭据时填写自己的 API Key。使用本地服务前先启动该服务。

刷新模型目录、选择模型，按界面测试并保存，设为当前使用。然后发一句普通聊天，确认能收到回复。目录请求成功不等于回答链路已验证。详细配置和排错见 [模型配置](MODEL-SETUP.zh-CN.md)。

**普通文字聊天不需要连接 Minecraft，也不要求先安装知识包或语音包。**

## 3. 按需连接 Minecraft

1. 核对正在玩的实例的 Minecraft 版本和加载器，从该版发布清单中选择对应基础 Bridge。
2. 退出目标游戏实例后，将对应基础 Bridge JAR 放入该实例的 `mods` 目录。每个实例只保留匹配平台的一套，不混放不同加载器或新旧同名 Mod。
3. 配方和特定模组能力按清单选装 JEI／REI 等附属，同时满足附属标明的目标模组和版本要求。**SDK、协议 JAR 不放进 mods。**
4. 启动该实例并进入世界，在客户端“连接”页刷新，选择实际在玩的实例，按提示配对。
5. 在“工具与扩展”检查相应能力的启用与可用状态，再试“我手上是什么”一类只读查询。

已有适配范围为 Forge 1.20.1、Fabric 1.20.1／1.21.1、NeoForge 1.21.1／26.3；各平台实际发放的 Bridge 和附属以发布清单为准。连接成功不代表所有工具可用，多人环境也不代表能读取服务端全部信息。

## 4. 按需加入知识与语音

在“知识库”导入适配的知识成品包，等待导入完成，再确认启用状态；不必因列表暂未加载而重复导入。在“工具与扩展”检查知识功能后，可以提问并展开回答中的资料来源。停用保留资料，卸载含义不同，操作前核对选择范围。

语音大包使用发布者提供的百度网盘入口和对应说明。在“设置 → 语音”导入、选择档位和设备并保存，等待准备就绪后测试输出。完整音色与参考音频使用各自入口，不把所有 ZIP 当成同一种包。

音色包下载入口：[语雀音色包页面](https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/nwnaga50cazb2v93)。音色包用于选择朗读声音，与提供识别／朗读环境的语音运行包分开；按页面说明选择适配格式，再使用客户端对应的音色或参考音频入口导入。

按界面显示的实际快捷键说话；快捷键和全局启用状态以个人配置为准。硬件要求取决于语音包与模型，不提供未经验证的统一最低显存承诺。

## 5. 确认自己要使用的功能即可

| 目的 | 可观察的结果 |
|---|---|
| 文字聊天 | 当前模型返回正常回复 |
| 游戏查询 | 结果对应当前实例与游戏状态 |
| 知识问答 | 能展开所引用的资料来源 |
| 语音交互 | 能取得输入文字并听到输出，按需分别检查 |
| 模组动作 | 附属和条件满足，观察真实游戏结果；回执不等于画面已变化 |

出现问题时查看 [常见问题](FAQ.zh-CN.md)，只收集与当前问题有关的必要信息，不反复重装全部组件。反馈前阅读 [数据使用与分享边界](DATA-USAGE.zh-CN.md)。
