玩家从 [下载与组件选择](../DOWNLOADS.zh-CN.md) 开始，首次使用看 [安装说明](../QUICKSTART.zh-CN.md)。本目录保存发布记录和维护者模板，不将模板中的待填项目显示成可下载附件。

每次发布复制 [发布说明模板](TEMPLATE.zh-CN.md)，用确认后的版本命名文档。客户端、Bridge、附属、语音包分别登记；已发布说明后续有修订时记录修订原因，不以同一版本悄悄替换不同产物。

二进制客户端与 JAR 经核对后作为 GitHub Releases 附件管理；大体积语音包沿用已有百度网盘分享。原始直播、个人数据、内部交接和本地工具不进入公开仓库。

0.1.210 为未公开候选，原说明与校验在本地保留，不作为公开下载版本。文档修订不强制升客户端版本，已公开附件修订须明确记录。
