# Bridge 与附属附件清单（0.2.0 配套发布）

已找到五端基础 Bridge 和 8 个附属，共 13 个 JAR。以下为实际文件及包内依赖声明；用户已选定 `MiAXion-JAR-collection.zip` 作为本批模组附件，已清理包内旧说明与本机路径，[下载模组合集](https://github.com/Kronos0523/MiAxion/releases/download/v0.2.0/MiAXion-JAR-collection.zip)；不能将组件版本统一写成客户端 0.2.0。来源提交沿用交付记录，未独立重建 JAR。

安装：退出目标游戏后，仅将匹配平台的基础 Bridge 和需要的附属 JAR 放入该实例 mods。不要把所有平台一起安装，不把 SDK／协议 JAR 当成 Mod。附属还需满足基础 Bridge 与目标模组条件。

## 来源与验证

精确字节、SHA-256、逐组件来源和包内依赖见 [机器可读清单](0.2.0-mod-files.json)。本轮核对 13 个文件与原交付哈希一致，并读取实际 JAR 元数据；未启动游戏。

原交付记录有四端基础 Bridge 的有限用户成功反馈；Forge 1.20.1 的这次版本未重测，不要求重复用户已豁免的验收。部分附属在交付清单中仍标 pending，应保持该边界，不把合集成功或客户端启动替代逐附属实测。当前客户端发布布局不要求重装已有匹配 JAR。

本批采用用户指定合集清理说明后的 ZIP；13 个 JAR 与原包逐字节一致。附件大小 44,037,929 字节（约 42.00 MiB），SHA-256 为 `2c91ae820ae5631c0d4644379a611175528a808e83fd62641fe2af812c174373`，详见 [附件记录](0.2.0-mod-archive.json)。下载链接待正式上传。发布者已于 2026-10-27 确认本批 JAR 的第三方分发事项核对完成，原有许可证和署名要求继续适用。
