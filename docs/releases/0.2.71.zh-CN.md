# MiAxion 0.2.71：第二次公测发布

本次更新Windows x64客户端、五平台Bridge及附属合集，并新增勇者之章3知识合集。各组件保留独立版本。

## 相比0.2.0

- 新增东方女仆附属接入，提供工作控制及空间语音等适配能力。
- 增加对话对象与独立上下文管理，完善对象切换与反馈。
- 增加定时任务、循环控制及周期只读游戏查询；具体操作取决于已适配能力和授权。
- 改进历史资料查阅、知识索引恢复及可迁移资源定位。
- 改进多对象请求、参数纠正、工具回执及状态结果的关联，减少遗漏及重复执行风险。
- 调整回复与朗读呈现：普通回答已有正文时不再固定追加成功摘要，真实回执及读取依据仍可在详情查看。
- 新增勇者之章3知识合集，含260个知识子包；资料覆盖和版本适配以实际内容为准。

## 下载与升级

客户端：[MiAXion-0.2.71-win-x64.zip](https://github.com/Kronos0523/MiAxion/releases/download/v0.2.71/MiAXion-0.2.71-win-x64.zip)（356.55 MiB）。完整解压到新目录后运行client/MiAXion.exe；保留app、assets及其他配套文件，包内含.NET/WPF，原生依赖仍需VC++ v14 x64。

模组：[MiAXion-JAR-collection.zip](https://github.com/Kronos0523/MiAxion/releases/download/v0.2.71/MiAXion-JAR-collection.zip)（42.12 MiB）。先解压，只安装匹配游戏版本与加载器的基础Bridge及所需附属。东方女仆附属仅用于 Forge 1.20.1，需 Bridge ≥0.1.32（本包为0.1.35）及女仆本体1.5.0，兼容范围[1.5.0,1.5.1)。本包不含女仆本体。其他附属依赖见包内 manifest.json。

知识包：[chapter-of-yuusha-3.zip](https://github.com/Kronos0523/MiAxion/releases/download/v0.2.71/chapter-of-yuusha-3.zip)（85.69 MiB）。通过客户端知识库导入整个合集ZIP，无需逐个拆开260个子包。

旧用户先退出客户端，保留旧目录，再将完整client/data复制到新目录。不要仅复制数据库，不要让新旧客户端同时使用同一份data。Windows凭据不包含在data备份中，换用户或电脑可能需要重新填写Key。回退使用旧客户端及升级前data。

其他六个知识包继续从v0.2.0 Release下载。语音包沿用百度网盘：https://pan.baidu.com/s/1Attd0pmh-a8Bm9AV95nrvg?pwd=9999 ，提取码9999。均衡款自带音色，高品质款需额外导入兼容音色包：https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/nwnaga50cazb2v93 。

## 验证与限制

发布者确认本次包已验证。附件另进行ZIP完整性、客户端清单逐文件校验、14个JAR哈希及260个知识子包完整性检查。用户验证与自动校验分别记录，不扩大为所有平台、模型和业务场景均通过。

仍为公测版本：模型可能漏调用、漏答或给出错误描述；应以实际游戏结果、回执和资料为依据。开发记录中的既有广回归失败不因此自动关闭。按需工具发现仍属于实验范围，未作为默认已验功能宣传。
