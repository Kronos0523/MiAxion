# MiAxion 0.2.0：自包含公测版

**[下载 MiAxion 0.2.0](https://github.com/Kronos0523/MiAxion/releases/tag/v0.2.0)**。客户端、模组合集和六个知识包在本次 Release 提供，语音包沿用百度网盘。

## 本次变化

首个公开客户端版本统一为 0.2.0，沿用此前自包含布局与业务。Bridge、附属、知识与语音包仍用各自实际版本。

应用依赖、.NET/WPF 运行时和语言资源统一打包，减少程序目录里的零散 DLL 与语言文件夹。保留检索模型、语言和既有业务依赖，未开启裁剪或 AOT。仍须完整解压，保留 assets 和许可证文件。

继续采用自包含部署，内含 .NET/WPF 10.0.13 win-x64，无需另装 .NET 或 SDK。ONNX 检索引擎仍需 Microsoft Visual C++ v14 x64；缺失时使用[微软官方安装入口](https://aka.ms/vc14/vc_redist.x64.exe)。

本次没有改变数据格式、权限或语音／游戏规则，也没有因发布布局变化要求更换已有匹配的游戏 Mod、附属或语音包。

## 升级与回退

正常退出旧客户端后，保留整个旧目录；把新 ZIP 解压至另一空目录，按 [升级说明](../UPGRADE.zh-CN.md) 将完整旧 `client/data` 复制到不存在或明确为空的新 `client/data`，再启动新版。不要共用活动数据库或只复制单个数据库文件。

复制 data 不等于备份 Windows 凭据存储中的全部模型密钥。换电脑或 Windows 用户时可能需重新输入凭据。回退使用旧程序及升级前的旧 data，不把新版写过的数据直接覆盖回去。
