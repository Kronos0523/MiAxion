# 问题反馈

仓库公开并启用 Issues 后，可使用问题模板提交；当前尚未公开时，将下列信息交给提供候选包的维护者即可，不需要自己查源码。

```text
问题简述：
客户端版本／来源提交（可从随包清单取得）：
发生时间与时区：
最短复现步骤或一条问题：
预期结果：
实际结果／错误码：
是否发生真实游戏动作或文件写入：
是否还能继续使用：

涉及模型：服务类型、模型名称、相关模式（不含 API Key）
涉及游戏：Minecraft、加载器、基础 Bridge 与附属版本、单机／服务器
涉及语音或知识：包名称、版本及当时状态
附件：脱敏截图、对应时段错误片段、请求 ID（若有）
```

日志位置可从“设置 → 应用数据目录”查看。已有交付中，`data/logs/settings.log`、`bridge.log` 和 `startup.jsonl` 分别可辅助核对设置／模型、游戏连接及启动退出过程；具体以所用版本实际文件为准，只分享相关片段。

已有游戏动作或文件写入时，不为复现而反复提交同一句请求。取消异常、卡住或崩溃时先保留现场，不清空历史或删除存档，也不默认重新安装全部组件。

提交前按 [数据分享说明](DATA-USAGE.zh-CN.md) 隐去凭据和个人内容。截图或日志不足时，维护者再提出具体补充项；不要主动上传完整 data、录音或数据库。
