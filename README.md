# MiAxion

在 Minecraft 里，用对话查资料、了解游戏状态，连接你正在玩的模组世界。

MiAxion 是一款面向 Minecraft 的桌面 AI 助手。它把模型对话、知识包、游戏连接和语音交互放在一起：遇到不熟悉的物品时查资料，需要配方时查询配方信息，也可以结合当前手持物品、背包等游戏信息继续提问。

当前客户端面向 Windows x64。游戏连接通过与 Minecraft 版本和加载器匹配的 Bridge 实现，配方和部分模组能力由附属提供。

## 可以怎样使用

### 玩到哪里，问到哪里

探索整合包时，不必先记住每个模组的用法。可以围绕眼前的物品、正在进行的任务或遇到的问题发起对话，再继续追问细节。

连接游戏并启用对应能力后，可以从“我手上是什么”“查一下背包里的铁锭”这样的请求开始。实时查询依赖游戏提供的信息；聊天历史里的状态不代表游戏此刻的状态。

### 把知识包带进对话

导入适合当前游戏和模组的知识包，让助手结合资料回答问题。知识包可以按需启用、停用和管理，回答中的资料入口可用于查看来源。

知识包负责提供参考资料，Bridge 负责取得可用的游戏信息。两者结合，方便从“这个东西是什么”继续问到“我接下来该怎么做”。回答质量仍取决于资料覆盖、版本和所选模型。

### 查询配方，连接模组能力

通过基础 Bridge 与对应附属，查询游戏状态、配方等信息，并使用已适配的模组交互能力。JEI／REI 配方附属和其他模组附属会在下载清单中分别列出。

部分已适配的模组界面操作可以从助手发起。能否执行取决于对应附属、工具启用状态和当前游戏条件；并非所有模组窗口或动作都支持，也不能把“请求已交给游戏”当作画面已经发生变化。

### 用语音继续交流

配置语音包和设备后，可以按自己设置的快捷键说话，并听取回复。语音功能按需启用，也可以先只用文字对话。

语音包独立提供，不同档位有不同的运行条件。具体安装方式、硬件要求和已有包的更新规则，以对应语音包说明为准。

## 开始使用

1. **取得完整客户端。** 正式下载入口正在准备，发布后提供对应安装说明与更新记录。
2. **配置自己的模型服务。** 在客户端设置中选择或填写服务地址、模型和必要凭据。使用本地模型服务时，需先启动相应服务。普通文字聊天不要求连接游戏，模型费用和网络要求由所选服务决定。
3. **按需连接 Minecraft。** 选择匹配游戏版本与加载器的基础 Bridge；配方和其他模组能力再选装对应附属，不要将不同平台的 JAR 混装到同一个游戏实例。
4. **添加知识与语音。** 根据自己的玩法导入知识包，需要语音时再安装相应语音包并配置设备。

客户端、基础 Bridge、附属和语音包分别管理，更新客户端不代表它们都需要更新。下载说明会明确每类文件的用途、适用范围、安装位置与更新要求。

大体积语音包沿用百度网盘分发，分享链接和提取码将在确认后补充。知识包的可分发内容及获取方式另行说明。

## 源码开放范围

MiAxion 选择部分组件开源。首批 [SDK、Java／C# 协议与 NeoForge 只读示例源码](components/public-contracts/README.zh-CN.md) 已整合，自有选定组件及公开接入 skill 采用 MIT，第三方依赖保留原许可证。当前仍为本地发布候选，Bridge 公共层与平台实现继续按组件审查。

客户端核心、模型编排、记忆和检索实现暂不在默认开放范围内。知识内容、模型权重、语音模型和参考音频的分发说明分别核对，不随项目的部分开源自动采用同一许可证。

本仓库用于项目介绍、用户文档、问题反馈、下载发布和选定组件源码。开发者可查看 [独立构建说明](components/public-contracts/docs/BUILD.zh-CN.md) 与 [组件许可声明](components/public-contracts/THIRD-PARTY-NOTICES.md)。SDK 与协议 JAR 不是可安装 Mod；源码目录中的示例也不代替基础 Bridge。

接入开发见 [Bridge 与附属开发入口](docs/BRIDGE-DEVELOPMENT.zh-CN.md)，具体边界见 [组件开放方案](docs/OPEN-SOURCE-SCOPE.zh-CN.md)。首批源码已通过 Linux 独立构建与协议测试；Windows 独立构建和示例游戏实测尚未完成，不代表五端基础 Bridge 源码均已开放。

## 已知边界与反馈

模型回答可能出错；资料版本、当前游戏状态和工具执行结果需要结合实际情况判断。基础 Bridge 能连接，不代表所有附属能力都可用；构建通过也不代表所有平台和整合包都经过实测。

正式发布后，可通过本仓库 Issues 反馈问题。请注明客户端版本、Minecraft 版本、加载器、相关附属版本、复现步骤，以及预期和实际结果。提供截图或必要错误片段前，请移除 API Key、配对凭据和个人信息，不上传完整个人 data 或聊天数据库。
